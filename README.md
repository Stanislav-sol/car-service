Car Service API

REST API сервис для автосервиса, по управлению машинами(с хозяином или без) и сервисным обслуживанием. 
Проект реализован с использованием событий Kafka, кэширования Redis и JWT-авторизации.

Технологический стек
- Язык: Java 17
- фреймворки: Spring Boot 3 (Web, Async)
- База данных: PostgreSQL 15, Spring Data JPA, Hibernate
- Асинхронные события: Apache Kafka, Zookeeper
- Кэширование: Redis 7
- Безопасность: Spring Security, JWT jjwt 0.12.5, Token Blacklisting, BCrypt
- Контейнеризация: Docker Compose
- Тестирование: JUnit 5, Mockito, Spring Boot Test

Основной функционал

Управление базой данных автомобилей, пользователей и сервисов (CRUD-операции). 
Аутентификация и авторизация пользователей. 
Валидация входных данных и централизованная обработка ошибок.

Архитектура и функциональные особенности    

Безопасность и Авторизация. 
Авторизация и аутентификация пользователей с помощью JWT-токенов. 
Ограничение прав доступа по ролям USER и ADMIN. 
Наличие docker compose документа для поднятие нужных контейнеров для работы сервиса и так же файлы настройки такие как application.yaml. 
Настройка разных профилей. 
Тестирование с помощью юнит тестов.

Бизнес-логика и Доменная модель

Управление сущностями User, Car и Service. 
Ограничения гаража(такие как вместимость) и обработка кастомнных исключений. 
Обработка ошибок через ControllerAdvice. 
Фоновые задачи CarInspectionTask.

События Kafka

Настроена отправка событий при добавлении и удалении машин car-created-topic, car-deleted-topic.

Кэширование и Оптимизация

Интеграция Redis через клиент Jedis для кэширования частых запросов. 
Асинхронные функции. 
Логирование входящих HTTP-запросов через и не только.

Запуск проекта

1. Поднятие инфраструктуры в Docker. 
В корневой папке проекта запустите контейнеры (PostgreSQL, Redis, Kafka, Zookeeper): 
docker-compose up -d

3. Запуск Spring Boot приложения. 
Приложение по умолчанию использует профиль dev (порт 8080): 
./mvnw spring-boot:run

Приложение будет доступно по адресу: http://localhost:8080

Тестирование

Для запуска юнит-тестов сервисов и контроллеров выполните: 
./mvnw test
